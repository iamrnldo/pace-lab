# PaceLab — Beginner Workout Development

## Tujuan

Mengembangkan template latihan Beginner berdasarkan referensi Q Session Daniels, tetapi disederhanakan dan disesuaikan dengan 5K, 10K, Half Marathon, dan Full Marathon.

Beginner tidak langsung menggunakan 2–3 Quality Session berat setiap minggu. Prioritasnya:

```text
Easy consistency → Long Run → Controlled quality → Race preparation
```

## Aturan Umum Beginner

- 1 Quality Session utama per minggu pada fase awal.
- 2 Quality Session hanya pada fase Specific Preparation jika recovery mencukupi.
- Minimal satu Easy/Rest day di antara sesi berat.
- Satu catatan ST per minggu pada hari Rest.
- Long Run menggunakan waktu pada 2 minggu awal General Preparation.
- Long Run menggunakan jarak setelah fondasi terbentuk.
- Tidak mengejar pace ketika tubuh belum siap.
- Recovery lebih panjang daripada Intermediate.

## Struktur Mingguan Beginner

Template umum:

```text
Senin: Rest / ST
Selasa: Easy atau Q session
Rabu: Easy Run
Kamis: Rest / Easy
Jumat: Tempo/Interval ringan jika fase mengizinkan
Sabtu: Easy / Rest
Minggu: Long Run
```

Jika atlet hanya memilih 3–4 hari latihan, Q session kedua dihapus terlebih dahulu.

# 5K Beginner

## General Preparation

Fokus:

- Easy Run.
- Long Run berbasis waktu.
- ST ringan.
- Strides belum wajib.

Contoh minggu awal:

```text
Senin: Rest + ST ringan
Selasa: 30–40 menit Easy
Rabu: Rest atau Easy 25–30 menit
Kamis: Easy 30–40 menit
Jumat: Rest
Sabtu: Easy 25–35 menit
Minggu: Long Run 40–45 menit berbasis waktu
```

## Specific Preparation

Mulai memasukkan satu quality session:

```text
Minggu A:
6 × 200m R dengan recovery jog 200m

Minggu B:
3–4 × 400m I dengan recovery jog 400m
```

Tempo baru diberikan terutama pada 4 minggu terakhir:

```text
2 × 6–8 menit T dengan recovery 2 menit jog
```

## Pre Competition

- Satu sesi T atau I per minggu.
- Volume quality dikurangi.
- Easy Run tetap menjadi mayoritas.
- Long Run diturunkan menjelang race.

## Competition Week

```text
1 Shakeout Run
Rest / ST ringan
Race Day 5K
```

# 10K Beginner

## General Preparation

Fokus:

- Easy Run.
- Long Run berbasis waktu pada 2 minggu awal.
- ST ringan.
- Tidak langsung menggunakan interval panjang.

Contoh progresi Long Run:

```text
Minggu 1: 50 menit
Minggu 2: 55 menit
Minggu 3: 6–7 km
Minggu 4: 7–8 km
```

## Specific Preparation

Satu quality session utama per minggu:

```text
Minggu A:
6 × 400m pada pace terkendali dengan 400m jog

Minggu B:
5 × 600m dengan 2 menit recovery jog

Minggu C:
4 × 800m dengan 2–3 menit recovery jog

Minggu D:
3 × 1000m pada 10K effort dengan 2–3 menit recovery
```

Tempo dapat digunakan setelah fondasi terbentuk:

```text
15–20 menit T kontinu
atau
2 × 8–10 menit T dengan 2 menit jog
```

## Pre Competition

- Interval lebih pendek.
- Tempo tetap dipertahankan tetapi durasinya berkurang.
- Long Run diturunkan.
- Tidak ada dua sesi berat berurutan.

## Competition Week

```text
2 Shakeout Run ringan dengan total 70% jarak lomba
Rest / ST ringan
Race Day 10K
```

# Half Marathon Beginner

## General Preparation

Fokus utama:

- Easy Run.
- Long Run berbasis waktu.
- ST.
- Tidak langsung memakai interval intensitas tinggi.

Contoh progresi Long Run:

```text
Minggu 1: 60 menit
Minggu 2: 70 menit
Minggu 3: 8–9 km
Minggu 4: 10 km
```

## Specific Preparation

Quality session lebih banyak menggunakan T dan M effort daripada interval cepat:

```text
Minggu A:
20 menit T ringan

Minggu B:
3 × 8 menit T dengan 2 menit jog

Minggu C:
2 × 15 menit T dengan 3 menit jog

Minggu D:
Long Run dengan 10–15 menit pada M effort
```

Interval ringan boleh digunakan:

```text
4–5 × 1000m controlled effort
```

Namun tidak dilakukan setiap minggu.

## Pre Competition

- Long Run mulai diturunkan.
- Tempo dipertahankan singkat.
- M effort digunakan dalam blok pendek.
- Easy Run menjadi mayoritas volume.

## Competition Week

```text
2 Shakeout Run dengan total 70% jarak Half Marathon
Rest / ST ringan
Race Day Half Marathon
```

# Full Marathon Beginner

## General Preparation

Fokus utama:

- Easy Run.
- Long Run berbasis waktu.
- Strength Training.
- Adaptasi jaringan tubuh.
- Tidak mengejar interval cepat.

Contoh progresi Long Run:

```text
Minggu 1: 75 menit
Minggu 2: 90 menit
Minggu 3: 10–12 km
Minggu 4: 12–14 km
```

## Specific Preparation

Fokus:

- Long Run.
- M Pace blocks.
- Tempo ringan.
- Easy mileage.

Contoh:

```text
Long Run 16 km dengan 3 km M effort

2 × 10 menit T dengan 3 menit jog

Easy Run + 20 menit M effort
```

Interval pendek hanya digunakan secara terbatas:

```text
6 × 400m controlled
```

Tujuannya menjaga economy, bukan mengejar VO2max tinggi setiap minggu.

## Pre Competition

- Volume Long Run diturunkan.
- M Pace dipertahankan dalam blok singkat.
- Tidak ada interval berat.
- Fokus recovery dan durability.

## Competition Week

```text
Shakeout ringan
Rest
Race Day Marathon
```

## Prioritas Beginner Marathon

```text
Long Run > Easy consistency > M Pace > Tempo > Interval
```

# Perbedaan Beginner dan Intermediate

| Elemen | Beginner | Intermediate |
|---|---|---|
| Quality session | 1 utama/minggu | 1–2/minggu |
| Recovery | Panjang | Sedang |
| Interval | Lebih pendek | Lebih panjang/kompleks |
| Tempo | Singkat | Lebih lama |
| Long Run | Progresif dan berbasis waktu | Lebih spesifik dan bisa memakai pace |
| ST | 1 catatan/minggu | 1–2 sesi/minggu |
| Taper | Volume dikurangi lebih konservatif | Intensitas lebih terjaga |
